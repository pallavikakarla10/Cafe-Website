# ☕ Aroma Café

A responsive multi-page café website built using HTML, CSS, and JavaScript.

## 📌 About the Project

Aroma Café is a modern café website designed to provide visitors with information about the café, its menu, gallery, and table reservations.

The website focuses on a clean, warm, and user-friendly design with responsive layouts for desktop and mobile devices.

## ✨ Features

- 🏠 Home page
- ☕ About section
- 🍰 Detailed menu
- 🖼️ Image gallery
- 📅 Table reservation form
- 📍 Café location with Google Maps directions
- ⭐ Customer testimonials
- 📱 Responsive mobile navigation
- ⬆️ Back-to-top button
- 📝 Contact form validation
- 📅 Reservation date validation
- 🕒 Reservation time validation
- 🎉 Reservation confirmation message
- 🔗 Social media links

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
